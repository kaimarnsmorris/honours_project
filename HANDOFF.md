## 1. Point `public/` at the GitHub remote

The `public/` directory has its own fresh git history (independent of this private parent).
Run the following from the root of this parent directory:

```bash
# Add the remote (only needed once)
git -C public remote add origin https://github.com/kaimarnsmorris/honours_project.git

# Verify
git -C public remote -v

# Review what will be pushed
git -C public log --oneline

# Push — choose one:

# (a) Fresh push (no prior commits on the remote)
git -C public push -u origin master

# (b) If the remote already has commits and you want to replace them
git -C public push --force -u origin master
```

Choose option (a) if you created the GitHub repository empty.  Choose option (b) only if the
remote has old commits you no longer want — force-push is destructive, so confirm first.
