# Variance Reduction for Training Neural Bayes Estimators

Companion repository for the honours thesis of the same name.

## Abstract

Neural Bayes estimators (NBEs) are amortised inference networks trained to minimise
expected loss under a prior–likelihood model.  This thesis investigates two variance-reduction
strategies for their stochastic training gradients.  Rao–Blackwellisation (RB) exploits the
conditional independence structure of the NBE loss to replace a Monte Carlo gradient with a
lower-variance Rao–Blackwell estimator; the thesis proves and numerically verifies that this
reduction is unconditional — RB gradients have strictly lower variance than plain MC gradients
for every architecture, prior, and batch size tested.  Importance sampling (IS) reweights the
prior distribution toward high-loss regions; the thesis shows that the resulting gradient
estimator has lower variance only conditionally, depending on the alignment between the
importance weights and the loss landscape, and derives the conditions under which IS helps or
hurts.  The empirical work uses a Normal–inverse-Gamma model that admits a closed-form Bayes
estimator, giving a tractable lower bound against which both strategies are benchmarked.

## How to run

### Install dependencies

```bash
pip install -r requirements.txt
```

A standard scientific Python environment with PyTorch is sufficient.  No special installation
beyond the requirements file is needed; the `nbe` package is loaded from `src/` by each
notebook via `sys.path`.

### Open the notebooks

Open the four notebooks in order (01 → 04) in Jupyter Lab or Jupyter Notebook.  Each notebook
is self-contained and can be read as a chapter companion without running any cells.

### `RUN_FULL` flag

Every notebook contains a cell near the top that sets:

```python
RUN_FULL = False
```

- **`RUN_FULL = False` (default):** cached results are loaded from `results/` and all figures
  are reproduced from those cached values.  The notebook runs to completion in under a minute
  on any machine with no GPU required.
- **`RUN_FULL = True`:** the full training and sweep loops are re-executed from scratch.  This
  may take several minutes to tens of minutes depending on hardware.  A CUDA GPU is optional
  but substantially reduces wall time for notebooks 02, 03, and 04.

## Environment notes

**Windows:** PyTorch ships with duplicate OpenMP libraries on Windows.  Set the environment
variable before launching Jupyter to avoid a runtime error:

```
set KMP_DUPLICATE_LIB_OK=TRUE
```

Or, equivalently, prepend it to the Jupyter launch command:

```bash
KMP_DUPLICATE_LIB_OK=TRUE jupyter lab
```

**GPU:** A CUDA GPU is optional.  With `RUN_FULL = False` (the default) all notebooks run
entirely on CPU.  With `RUN_FULL = True`, notebooks 02, 03, and 04 perform neural-network
training; a GPU reduces typical run times from tens of minutes to a few minutes but is not
required for correctness.
